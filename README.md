# Spadafore Law, LLC

Modern redesign of the Spadafore Law landing page — Next.js, Tailwind CSS, shadcn/ui, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- shadcn/ui
- Framer Motion
- Lucide icons
